# Security policy

## Supported versions

Security fixes target the latest tagged release. Update to the latest release before reporting an issue.

## Report privately

Use GitHub's **Security → Advisories → Report a vulnerability** for this repository:

https://github.com/adamauthor/vpn-keeper/security/advisories/new

Provide the affected version, expected boundary, impact, and a minimal **synthetic** reproduction. Do not include a real QR export, password, TOTP secret, OTP value, private VPN host, or an unredacted Cisco diagnostic bundle.

If private reporting is unavailable, open a public issue containing only a request for a private contact channel. Do not disclose the vulnerability or sensitive data in that issue.

Please allow time for a fix before public disclosure. This is a small community-maintained project; no response-time or bounty program is promised.

See the [security architecture](docs/SECURITY-ARCHITECTURE.md) for the credential path and threat model.
